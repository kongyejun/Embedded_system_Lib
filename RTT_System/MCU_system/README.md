# Log System

一个面向 MCU 的轻量级日志系统,基于 SEGGER 实现。为节约数据传输成本,采用自定义的 `log_vsnprintf` 格式化方案:字符型参数直接嵌入字符串,数值型参数以原始二进制数据传输,由上位机负责解析还原。

## 目录结构

\`\`\`
.
├── SEGGER/              官方 SEGGER 工程(含自实现的 log_vsnprintf)
└── log_system/          MCU 侧日志实现
    ├── inc/             工程头文件
    ├── test/            测试及辅助代码
    ├── log_protocol.c   协议层(格式化层)
    └── log_system.c     用户层(用户 API 接口)
\`\`\`

## 核心设计

### 为什么要自实现 log_vsnprintf?

标准 `vsnprintf` 会将所有参数在 MCU 侧格式化为 ASCII 字符串,数值越大占用字节越多,且消耗 MCU 算力。本方案通过"延迟格式化"降低传输量与 MCU 负担:

- **字符型参数**(`%c` / `%s`):直接嵌入到发送字符串中。
- **数值型参数**(`%d` / `%x` / `%f` 等):保留占位符,其后紧跟定长原始二进制数据,格式化工作移交上位机完成。

### 示例

调用:

\`\`\`c
log_printf("System %s time:%d\n", "init", 32);
\`\`\`

MCU 侧实际发送的数据:

\`\`\`
System init time:%d[int32_t 原始字节]\n\0
\`\`\`

说明:

| 部分 | 处理方式 |
| ---- | -------- |
| `%s` → `"init"` | 字符型,直接嵌入字符串 |
| `%d` → `32` | 数值型,保留 `%d` 占位符,其后紧跟 4 字节 `int32_t` 原始数据 |

上位机接收后,按占位符读取后续原始字节并还原为最终可读日志。

## 分层说明

| 层级 | 文件 | 职责 |
| ---- | ---- | ---- |
| 用户层 | `log_system.c` | 对外提供日志 API 接口 |
| 协议层 | `log_protocol.c` | 实现 `log_vsnprintf` 格式化(字符嵌入 + 数值透传) |
| 底层传输 | `SEGGER/` | SEGGER 数据收发 |
